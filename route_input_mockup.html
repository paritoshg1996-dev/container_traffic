SmartRouteInput — proposed 3-line display

Line 1 = Area/City  ·  Line 2 = State  ·  Line 3 = Pincode. Each line shrinks independently if its own text overflows.

Example 1 — short text (default sizes)

Origin
Indore
Madhya Pradesh
452001
✕
→
Destination

Maharashtra
411001
✕

Default font sizes: L1 = 20px, L2 = 15px, L3 = 12px.

Adaptive font ladder (per line)

  • Line 1 (Area/City): 20 → 18 → 16 → 14 → 13 → 12px (based on char length)
  • Line 2 (State): 15 → 14 → 13 → 12 → 11 → 10 → 9.5px
  • Line 3 (Pincode): 12 → 11px (always 6 digits, rarely needs shrinking)

Each line is measured independently, so only the overflowing line shrinks — the hierarchy L1 > L2 > L3 is always preserved.
